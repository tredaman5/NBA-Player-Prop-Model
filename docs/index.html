About this project

This project generates points/rebounds/assists projections for NBA players using rolling performance features, opponent context, and pregame injury information, then compares those projections against sportsbook lines.

Methodology note: an early version of the minutes model had a data leakage bug -- it used a game's own actual box score to predict minutes in that same game, making its accuracy look better than it really was. That bug is fixed, and every number below reflects the honest, leakage-free pipeline. Model performance is measured against a naive rolling-average baseline; a real test against sportsbook closing lines is planned once enough live-season data accumulates (see below).

Model Performance

Lift = improvement over a naive "last-N-games rolling average" baseline, on held-out (chronologically later) games.
